ScriptsScripts

node seo/scripts/inventory.mjs              # pages, keywords, internal link graph
node seo/scripts/check-article.mjs <slug>   # mechanical check (--all for the whole blog)
node seo/scripts/suggest.mjs "<topic>"      # Google autocomplete expansion
node seo/scripts/gsc.mjs                    # report on the latest Search Console export

Les scripts n'inventent rien : sans réseau, l'autocomplétion s'arrête et le dit. Les « hits » comptent les expansions qui renvoient une suggestion, ce n'est pas un volume de recherche. The scripts never make data up: without network access the autocomplete script stops and says so. "Hits" count how many expansions returned a suggestion; they are not search volumes.

Search Console

Une fois par mois : Performances, Résultats de recherche, 3 derniers mois, Exporter, CSV. Décompresser dans seo/data/gsc/AAAA-MM-JJ/. Les en-têtes français et anglais sont reconnus. Once a month: Performance, Search results, last 3 months, Export, CSV. Unzip into seo/data/gsc/YYYY-MM-DD/. French and English headers are both supported.

Le dépôt est public. seo/data/ et seo/.cache/ sont ignorés par git, donc tes données Search Console restent sur ta machine. Le backlog et les briefs sont versionnés et donc lisibles par tous. Règles qui ne bougent pasRules that never change

  • Aucun chiffre, client, témoignage ou étude sans source réelle vérifiée par l'éditeur.No figure, client, testimonial or study without a real source checked by the editor.
  • Un article par intention de recherche. Un sujet déjà couvert enrichit l'article existant.One article per search intent. A covered topic enriches the existing article.
  • Pas de publication sans pull request relue, ni de merge automatique.No publication without a reviewed pull request, and no automatic merge.
  • Commits et pull requests sans trailer ni mention de l'outil qui a produit le contenu.Commits and pull requests carry no trailer and no mention of the tool that produced the content.
  • Ne pas publier est un résultat valide.Not publishing is a valid outcome.
